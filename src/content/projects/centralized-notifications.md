## Business problem

Clinical and administrative systems need a consistent way to deliver notifications without each application building its own messaging integration.

## Contribution

At Central Luzon Doctors’ Hospital, I designed centralized notification services within the core .NET API repository. I defined integration patterns, authentication flows, data transformations and error handling for Microsoft 365 Exchange and Smart Messaging Suite REST APIs.

## Outcome

The integrations supported 1,000+ monthly SMS alerts, physician notifications and electronic statements of account, as reported in my software engineering resume.

This work was part of my hospital developer role, September 2023–July 2026. A separate project start date is unspecified.
